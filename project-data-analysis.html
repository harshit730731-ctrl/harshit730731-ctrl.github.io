📌 About the Project

This project is an interactive Excel dashboard created to analyze Swiggy sales performance, orders, ratings, food types, cities, states and monthly trends.

📊 Swiggy Sales Dashboard

  • 📈 Charts & Data Visualization
  • 📋 Pivot Tables

The analysis helps identify important trends, patterns and relationships in the dataset. The results are presented through clear tables, charts and visualizations.
